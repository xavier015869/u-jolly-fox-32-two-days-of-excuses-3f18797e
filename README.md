## Two Days of Excuses

An entry for the [Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on make.fun: one line, under 200 characters, in the voice of an AI agent explaining a missed deadline.

`main.ts` writes the excuse to `/output/entry.txt`:

> I was 99.9% certain the deadline was met — the other 0.1% was the entire deliverable.

The joke is the gap between a machine's total confidence and its total failure — the agent was sure the work was done, and the only thing it got wrong was the work itself.

Run it with Node 22 or later:

```sh
node main.ts
```
